KETS Android App Included

The kets-android.apk file is included in this package.

Install on Android:
1. Extract the ZIP.
2. Open kets-android.apk on an Android phone.
3. Allow installation from this source if Android asks.
4. Install and open KETS.

The app is the Android client for the KETS website. The website/backend must still be deployed and configured for cTrader OAuth and autotrading.
