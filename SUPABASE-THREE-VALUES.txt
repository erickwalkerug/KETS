KETS Supabase configuration
============================

KETS uses exactly these three Supabase environment variables:

SUPABASE_URL=your Supabase Project URL
SUPABASE_PUBLISHABLE_KEY=your Supabase Publishable Key
SUPABASE_SECRET_KEY=your Supabase Secret Key

The Publishable Key may be used client-side. The Secret Key is server-only and
must only be stored in Render environment variables.

No SUPABASE_SERVICE_ROLE_KEY, SUPABASE_SERVER_KEY, DATABASE_URL, PostgreSQL
connection string, or SQLite database is required by KETS.

After deploying, test /api/health. It performs a real read-only Supabase
probe and should return HTTP 200 with database.code=DB_OK.
