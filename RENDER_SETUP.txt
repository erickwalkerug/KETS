KETS STORAGE SETUP

- Storage: SQLite on a Render Persistent Disk.
- Persistent disk mount path: /var/data
- SQLite database file: /var/data/kets_website.db
- KETS_DATA_DIR is set to /var/data.
- No Supabase database is used.
- No Render PostgreSQL connection is required for this SQLite build.

Render service settings:
- Build command: pip install -r requirements.txt
- Start command: gunicorn app:app --workers 1 --threads 4 --timeout 120
