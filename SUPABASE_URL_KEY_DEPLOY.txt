KETS — FINAL SUPABASE DEPLOYMENT CONFIGURATION

Render environment variables:
SUPABASE_URL=https://YOUR-PROJECT.supabase.co
SUPABASE_SECRET_KEY=YOUR_SERVER_ONLY_SUPABASE_SECRET_KEY

If your Supabase project still uses the older service-role JWT instead of a modern
secret key, use this variable instead:
LEGACY_SERVICE_ROLE_KEY_NOT_USED=YOUR_SERVICE_ROLE_KEY

SUPABASE_PUBLISHABLE_KEY is the client-side key; SUPABASE_SECRET_KEY is required for backend operations
writes when Row Level Security protects the public tables.

SECURITY:
- Put the secret/service-role key only in Render environment variables.
- Never put it in index.html, app.js, Android code, or any browser-visible config.
- Do not commit the real key to Git.

The KETS backend uses the server-only key for trusted REST operations. This allows
registration, payments, and signals to work while RLS remains enabled.
