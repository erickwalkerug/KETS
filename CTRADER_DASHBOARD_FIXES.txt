KETS cTrader dashboard update

This build keeps the existing KETS signal/strategy logic intact and fixes the cTrader management display/actions.

Changes:
- Reads the selected cTrader account's live balance from ProtoOATrader.
- Displays equity, free margin, today's realized P/L, open/unrealized P/L and open-trade count.
- Uses the cTrader account deposit currency returned by the API instead of forcing USD.
- Refreshes the cTrader account snapshot automatically while the Managed Trading page is open.
- Refreshes the cTrader access token when the stored access token is expired.
- Uses cTrader symbol lotSize/minVolume/maxVolume/stepVolume when converting the user's lot-size setting to order volume.
- Fixes Close All to use the correct cTrader Close Position request (2111).
- Preserves the existing KETS strategy and signal filtering.
- Buttons now show Working/Sending/Closing/Saving states and report success/error in the page.
- Deposit/Withdraw buttons now show clear broker-directed instructions without pretending KETS holds funds.

Important:
- The displayed balance/P&L comes from the selected cTrader account only after cTrader authorization and account selection.
- A demo account can legitimately show a zero balance if that demo account has no funds.
- Live trading remains controlled by the connected cTrader authorization and the user's settings.


Additional reliability fix:
- cTrader WebSocket requests now match responses by clientMsgId and expected payload type, preventing asynchronous account events from being mistaken for the balance response.
- The dashboard rejects an account snapshot that contains no balance instead of silently displaying USD 0.
- Equity/free margin prefer values supplied by cTrader when available and otherwise use the open-position P/L and used-margin data.
- The dashboard no longer uses a misleading “Broker connection is not configured yet” message after cTrader has connected.


Final balance reliability fix:
- ProtoOATrader balance is now requested and processed before secondary requests.
- Failures in positions, P/L, deal history, or asset/currency lookup can no longer discard a valid balance and make the dashboard fall back to USD 0.
- The selected cTrader account ID is used for account authorization and Trader requests.
- Trader payload parsing accepts the normal payload.trader shape and a direct-payload fallback.
- Secondary-data warnings are shown separately while the live balance remains visible.
