KETS — SUPABASE PERMANENT STORAGE

1. Run the final SQL schema in Supabase SQL Editor.
2. In Render → KETS → Environment, add:

SUPABASE_URL=https://YOUR-PROJECT.supabase.co
SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY

3. Keep the database password private. Do NOT put it in the frontend.
4. Keep these signal bridge variables configured:

KETS_SIGNAL_SOURCE_URL=https://my-btc-bot-l0xm.onrender.com
KETS_SIGNAL_SOURCE_KEY=<same secret as trading bot>
KETS_SIGNAL_RECEIVER_KEY=<same secret as trading bot>
KETS_DISABLE_ENGINE=0
KETS_DISABLE_SOURCE_BRIDGE=1

5. Redeploy KETS.

The website uses Supabase REST API for users, profiles, payments and signals.
The trading bot remains the strategy engine and sends signals to /api/signals.
The browser never receives the Supabase database password or the bot API secret.
