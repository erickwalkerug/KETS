KETS DATABASE CONNECTION FIX
=============================

This package preserves the existing KETS setup, strategy, schedules, pricing,
frontend, payment configuration, signal receiver, and Supabase storage design.

Only the database connection handling was hardened:
- SUPABASE_DB_URL remains the preferred Render variable.
- Existing DATABASE_URL remains supported.
- If a Supabase pooler URL is accidentally supplied with port 6543,
  bot.py automatically uses Session Pooler port 5432 for this persistent
  Gunicorn service.
- No database password is stored in this ZIP.

Render:
Set SUPABASE_DB_URL (or keep the existing DATABASE_URL) to the connection
string copied from Supabase. Keep the password in Render Environment Variables,
not in the source code.
